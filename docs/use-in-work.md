# Using Design With Character in ChatGPT Work

Start in a Work conversation with the website or its source attached. If the personal skill is installed, select **Design With Character** from your skills or ask for it by name. A collaborator can also attach this repository ZIP and ask Work to read `skills/design-with-character/SKILL.md`. That entry point works without an account-specific link, internet search, or the example site.

## Give it a brief it can act on

> Use Design With Character on this community cinema site. First-timers want to find a screening. Regulars arrive from a film link and check whether the Q&A is still scheduled. Keep the existing tickets flow and accessible seating instructions. Our projectionist marks reel changes in yellow pencil. Show me the listing and one rescheduled screening on a phone before applying the direction to the archive.

The audience, return visit, nonnegotiables and real physical detail are doing different jobs. The skill can choose a composition from them. A named house style is optional. If a reference is available, point to the moment that matters, such as a pressed sheet opening, the cat changing posture, or the way a control shows a changed beat. If the existing site already has a visual identity, supply two accepted screens and the routes they represent.

| What you want | A request you can give Work |
|---|---|
| Pick a direction | “Use Design With Character. Show two directions with different actions for this artist’s oral-history archive. Explain what happens when someone returns after playing half an interview.” |
| Revise a specific screen | “Keep our controller bindings and the approved sprite. Revise just the resting and paused states. Show both on a short phone and preserve focus when I resume.” |
| Make a large website | “Map the visitor journeys and page families first. Prototype the entrance, the busiest task and one awkward case. Build the rest after those decisions hold together. Inspect them at phone and desktop sizes.” |
| Get original artwork | “Art-direct one GPT Image element for this screen. Leave the controls and title in HTML, include the crop needed for a phone, and record where the asset came from.” |
| Try a house style | “Use Halftone Dossier for this lost-and-found story. Choose a physical action a visitor can take with the evidence. Retain our existing search behavior.” |
| Add a style | “Read CONTRIBUTING.md, create a draft based on this pottery class, and prove a second subject can use it. Walk the gallery and contributor checks before publishing it in the local catalog.” |
| Get a release review | “Run the four review passes. Have a fresh reader try arriving directly at a detail page. Fix the findings, exercise changed states again, and tell me what remains unverified.” |

Work can operate directly on the target repository. The example gallery, demo CSS and art can stay in this kit. Read a style's guide only when it helps with the actual product. The kit can travel between repositories, and its optional project CLI runs on Python's standard library.

## Handoff to the next conversation

Keep a few small facts in the target project: the decisions that remain fixed, where each route family lives, the representative journeys a reviewer should exercise, and the actions that still need a device or human evaluation. Point the next chat there. If a saved move list belongs in an internal project, keep it local. Publishing client copy or screenshots requires the appropriate rights.
