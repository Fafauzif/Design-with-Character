# Find a direction that survives use

## Ground the choice

Inspect the user's supplied work first. For a redesign, open one path that already feels right and one that feels wrong. Keep a tiny inventory of the existing affordances, copy, assets, content density, and platform constraints a replacement must support. When a reference is unavailable, distinguish the user's description from what you actually observed.

Read a reference as a designer could reproduce it with entirely different assets. Find which edge the eye enters from, what owns the largest area, where the visitor acts, and what the screen becomes. Classify the borrowed idea as composition, behavior or material. Keep only the parts that fit the new subject. A licensed demo's source, prompts, fonts, and third-party artwork may have different terms. Record the exact material reused.

For an open brief, make quick competing sketches using the same title, content and action. Change something structural between them. For example, a group of singers could be discovered by opening a printed program, by choosing a voice in a listening circle, or by finding a song through its first line. Tie a decision to a real constraint, such as singers returning to rehearse one passage. Try the chosen option on an internal page and in a quiet state.

If choices converge on familiar editorial styling, inspect the concept's assumptions. Replacing a hero grid with a paper dossier is still an automatic decision if every project ends up on paper. If context is thin, use one bounded stimulus such as camera distance, viewing angle or a verb pulled from the user's material. Discard it when its only rationale is novelty. Keep core tasks immediately recognizable.

## Subtract and redirect attention

Test the interface once with decorative scaffolding suppressed. Look at the remaining content and order of operations. Restore the affordance that makes a control findable, the rule that lets someone track a row, or the flourish that visibly belongs to the subject. Leave out numbered process badges, ornamental header rules, explanation of a self-evident action, duplicate calls to action, and apparent controls without a meaningful result. Examine the changed state with equal care. An empty notebook still needs a way to start writing.

Use deliberate scale changes. A different type size should communicate a different reading priority at actual phone and desktop sizes. Group captions with their subjects. Assign the surface, foreground, accent and state cues a function. Sample real rendered combinations, including text on images, pressed and focus states, and accents used as outlines. Pick an unconventional accent when it earns a clear job. A palette ratio cannot tell you whether someone noticed the button.

## Remember expressive choices locally

When a project opts into continuity across sessions, keep a brief, project-local history. If the source kit supplies a format, use it. Otherwise a short table suffices. Store only the chosen composition, visitor action, material cue, observation that justified it, and scope for reuse. Record a rejected direction only when it saves future debate. An example entry is “Song view | start at a first line | hear one isolated part | repeat visitors know the line but forget the title | keep on song pages.” Review recent entries before a new concept. Preserve familiar controls across the same site and challenge an expressive idea that reappears without the same justification. Avoid cross-client details, names of private people, raw prompts with personal data, and global tracking.
