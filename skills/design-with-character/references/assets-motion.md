# Art direction and interactive material

## Commission the piece the layout needs

Decide the placement in the real layout before requesting art. A single image may carry the entrance. Six detail pages may require consistent perspective and six genuinely different silhouettes. Name the source and permitted use for existing work. Obtain approval for a change to an established mascot or brand identity if it changes the brief.

For GPT Image, describe the object, action or rest state, viewing angle, material, lighting, field color, crop, edge treatment, intended display size, and space needed for live text. Attach an approved reference for a consistent character when available and authorized. Preserve a recurring feature across the family while changing pose or composition to tell the difference. Use a transparent output for a cutout if the interaction needs it. Prefer text, fields, status, numerical values and interaction targets in HTML; draw exact, data-driven diagrams or sprite states in code where precision matters.

Example brief for a fictional instrument: “A little brass cup balances on a pale ceramic wheel. Show the instrument in left profile at tabletop height, the wheel's slots visible. Amber patina on the cup; deep blue-gray ground. Full object with space around the rim, even at a square crop. I will place the name and measurement beside it in HTML.” For a detailed study, request a second view of the joint when the joint itself explains the reading. A zoom of the same image cannot reveal a hidden mechanism.

Record each shipped asset or coherent group with its local path, role/route, origin and creator or generator, license/permission or generation basis, changes, and a source URL or brief where applicable. Exclude confidential reference inputs and identifying prompt details from public records. For uncertain redistribution rights, use an original substitute, obtain permission, or keep a reference link only.

Inspect art in its actual component. Check edge visibility against its ground, tiny crops, overlap after the copy wraps, and meaning with images disabled. Give informative images useful alt text; mark decorative images as such. Measure encoded size and loading behavior against the project's likely connection. Export suitable resolution variants when the main art dominates download size. If art generation is unavailable, choose an implementable form that still supports the task, such as existing approved photography, an intentional type composition, or original programmatic pixel art. Report the actual medium.

## Make motion legible and optional

For each distinctive action, write its trigger, useful feedback, interruption behavior, settled state, and reduced-motion equivalent. Prioritize the response to the action that just happened. A frequently used filter should update on input. A rarely seen unfolding invitation can take more time if the visitor can still proceed. Keep controls for required tasks reachable without waiting, hovering, dragging, scrolling an exact distance, or turning on sound. Provide a comparable keyboard/touch path for spatial gestures.

Check rapid repeats, Back during a transition, and switching reduced motion on before load. Render the settled state directly when reducing motion. Use text, shape, position or a useful state label to carry meaning when a sequence is off. Decorative motion should have a clear endpoint or controls appropriate to its use. For sound, start after a deliberate action and verify the visual state and any mute/stop control. Audio API events provide different evidence from listening to playback.
