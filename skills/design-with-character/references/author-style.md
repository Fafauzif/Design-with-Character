# Teach the next style

Begin with a real brief, an action and an observed gap in the existing catalog. Compare the candidate with its nearest sibling using the same content. If the visitor's path, composition and state change all remain the same under a grayscale inspection, explain the genuinely different use case or give the existing family a variant.

Build the smallest real experience that tests the difference. Include a working action, visible changed state, route to repeat or undo when appropriate, small-screen behavior, and direct keyboard access. Carry the idea to a second subject or route in writing, specifying what changes. A second coat of paint on the original subject cannot prove transfer.

Write a style record covering audience and bad-fit cases, opening composition, primary action and feedback, family-level variations, type/surface/accent roles, art or generation notes, motion and interruption, reduced motion, input and mobile behavior, asset provenance and the most revealing tests. In the gallery, show the actual opening and a materially different state at readable scale; tell a prospective user what they can do. Avoid presenting tool validation as user-facing copy.

In the full source kit follow CONTRIBUTING and the scaffold/build/check commands in that checkout. Use relative paths and its current manifest schema. Add the working HTML, style record, lawful/attributed artwork and preview assets, and update any style selector the project distributes. Open the generated link from a freshly extracted copy. Test the new entry and an existing entry. Without a kit, keep the style record, one example and its assets together and register it in the site's existing navigation or design guide. Avoid creating a second build system when an existing one can do the work.

For future maintenance, state one or two tradeoffs the next author might otherwise erase. Example: keep a drum sequencer's pads immediately responsive even when the workshop's entrance animation evolves. Add a regression test for the behavior and give the reviewer a visual sample where judgment is needed.
