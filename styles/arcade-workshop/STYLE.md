# Arcade Workshop

Give the page one instrument with a recognizable shape. Identify the user's input and put its response on the same object. Pulse Machine uses an eight-step drum pattern. The playhead crosses the step marks, an active pad physically drops when pressed, and the step edit changes the loop heard on the next pass.

Use persimmon for the molded body, deep brown for the recessed parts, and ochre for the main switch. Restrict numerals and monospaced labels to machine marks. Give active pads a contrasting fill and a physical-looking dot. Use a visible, native keyboard-operated slider and 24 real toggle buttons.

Offset the performance surface from its supporting materials. In this demo the secondary paper slips show each preset’s kick track. If the slips start below the viewport, they enter once as they scroll into view. Keyboard focus reveals them immediately, and reduced motion shows the whole tray and avoids the movement. Playback still indicates the current beat. Keep a Stop control near any secondary player view, and return focus to its current selection when that Stop control disappears.

The layout and code are original. This direction draws on Lemo-Opuscar's Games station for the idea that an interaction needs its own visual frame, and on physical drum machines for the recessed keybed and exposed tempo slider. The audio is synthesized locally from oscillators and filtered noise. The design requires no image or media assets.

## Across a larger site

In a sound workshop, the machine belongs at the playing bench. An instrument directory needs playable excerpts and recognizable silhouettes. A saved session needs its tempo, pattern and a direct return to playing. Echo the amber cue for playback across both jobs and preserve the same keyboard behavior. Keep pattern editing as simple buttons when the viewport cannot support a whole cabinet. Offer an explicit start and stop anywhere audio can play.
