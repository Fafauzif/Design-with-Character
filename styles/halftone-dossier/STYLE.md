# Halftone Dossier

Build the screen around a file someone can open. Let one subject cross a paper edge. Use ink and precise cropping to hold the subject in the composition. Keep halftone dots around the artwork, leaving reading space clear.

Use cream paper, a plum ink and a sparing deep raspberry accent. Use a heavy print face for the case title, neutral body type and compact file metadata. A rule should help read the evidence or handle a control. Use a short, tactile pull-out transition for the open state. Reserve a printed stamp for an action which changes the record. Keyboard and reduced-motion users can open the same file and reach the same evidence. Return focus to the opening control when the file closes, including after Escape.

Pip is a fictional cat illustrated with GPT Image for this case. The design and implementation here are original. Visual reference: [Halftone Dossier from Lemo-Opuscar by Lemomo](https://lemomo-ai.github.io/lemo-opuscar/styles/halftone-dossier/).

## Across a larger site

A dossier works when several clues refer back to the same person, object or event. On a neighborhood oral-history site, a person's portrait could hold a case open while transcripts and recordings supply the evidence. Let the collection view scan quickly by face and name. Keep transcript pages quiet enough to read. Reserve the stamp for a real recorded decision, such as finishing or saving a case, and supply a plain text confirmation. Skip the dossier sequence for repeat visitors who already know the record they want.
